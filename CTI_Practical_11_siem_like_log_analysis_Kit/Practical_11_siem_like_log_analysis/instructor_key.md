# Instructor Key — Practical 11 SIEM-Like Log Analysis

Expected finding: The process result is E02. Network results include E05-E09 at threshold 70; E10 is excluded.

Discussion focus: Run process and feed-enriched network searches; tune the score threshold.

Extension check: Rerun --query process and --query network; change --min-confidence to 95 and explain changes.

Do not treat simulated confidence scores as calibrated probabilities. Students should cite the dataset, distinguish analyst inference from a direct log observation, and explain why the result has limits.
