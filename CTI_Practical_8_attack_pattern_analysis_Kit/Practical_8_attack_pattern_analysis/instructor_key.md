# Instructor Key — Practical 8 Attack Pattern Analysis

Expected finding: WS-25 status GET gaps are [5, 5] minutes and one POST is 4,200,000 bytes; intent is not proven.

Discussion focus: Order the event sequence and calculate intervals between repeated /status contacts.

Extension check: Rerun with --host WS-50; compare the pattern and explain the difference.

Do not treat simulated confidence scores as calibrated probabilities. Students should cite the dataset, distinguish analyst inference from a direct log observation, and explain why the result has limits.
